# MM4SG workshop website

Static GitHub Pages website for the International Workshop on Multimodal Content Analysis for Social Good.

- `/` and `/WebConf27/`: fifth workshop (Dublin, 2027; dates tentative)
- Past-edition links on the main page open the original Google Sites, preserving
  their complete programs, committees, keynotes, and media.
- The existing `/WebConf26/`, `/WebConf25/`, `/ICDM24/`, and `/WebConf24/`
  routes remain as lightweight fallback/archive pages.

The site uses plain HTML, CSS, and JavaScript and requires no build step.
